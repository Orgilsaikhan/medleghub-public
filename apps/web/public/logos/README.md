# Ангиллын лого файлууд

Лого файлаа **ангиллын түлхүүрээр нэрлээд** энэ хавтсанд хийхэд хангалттай.
Код засах шаардлагагүй.

```text
public/logos/html_css.png    →  HTML/CSS сургалт
public/logos/python.svg      →  Python сургалт
```

Дараагийн `npm run dev` эсвэл `npm run build` үед бүртгэл автоматаар
шинэчлэгдэж (`scripts/generate-logo-manifest.mjs`), тухайн ангиллын кодод
зурсан хувилбарыг орлоно. Файлгүй ангилал зурсан хувилбараа ашигласаар байна.

Гараар шинэчлэх бол:

```bash
npm run logos:manifest
```

## Ангиллын түлхүүрүүд

```text
html_css   javascript   python   c       csharp
java       react        backend  database  git
```

Өөр нэртэй файлыг алгасах бөгөөд анхааруулга хэвлэнэ.

## Файлын шаардлага

| Шаардлага | Шалтгаан |
|---|---|
| **SVG** байх (PNG биш) | Ямар ч хэмжээнд тод. PNG нь өндөр нягтралтай дэлгэц дээр бүдгэрнэ. |
| **Тунгалаг дэвсгэртэй** | Карт бүрийн өнгөт дэвсгэр дээр тавигдана. |
| Илүүц зайгүй | Логог хүрээндээ бүрэн дүүргэнэ. |
| Бараан лого бол харанхуй горимд шалгах | Бараан дэвсгэр дээр алга болж болзошгүй. |

PNG ашиглах бол дор хаяж 192×192 байлга.

> **Анхаар:** интернэтээс татсан "тунгалаг" PNG-үүд ихэвчлэн шатрын хээг
> зурагтаа шингээсэн байдаг — жинхэнэ тунгалаг биш. Тэдгээр нь картан дээр
> цагаан хайрцаг болж харагдана. Бүртгэл үүсгэгч үүнийг илрүүлж
> анхааруулга өгнө.
